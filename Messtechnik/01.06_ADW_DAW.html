6  ADW–DAW — Grundlagen und Kenngrößen

Verwendete Symbole:

\(f_{a}\) … Abtastfrequenz

\(T_{a}\) … Abtastperiode

\(f_{g}\) … höchste im Signal enthaltene Frequenz

\(n\) … Auflösung des Wandlers in Bit

\(U_{ms}\) … Messbereichsspannbreite

\(\Delta U\) … Quantisierungsstufe (1 LSB)

\(\Delta Q\) … maximaler Quantisierungsfehler

Rechner verarbeiten Signale nur in digitaler Form. In der Messkette wandelt der ADW (Analog-Digital-Wandler) das analoge Sensorsignal in Zahlenwerte; der DAW (Digital-Analog-Wandler) macht den Weg zurück, z. B. zum Stellantrieb:

Sensor → (Verstärker) → ADW → Rechner → DAW → (Leistungsstufe) → Aktor

Beide Umwandlungen bestehen aus denselben Teilschritten:

  • Abtastung: Das zeitkontinuierliche Signal wird zu festen Zeitpunkten abgetastet — nur zu diesen Zeitpunkten liegt ein Wert vor.
  • Quantisierung: Der Abtastwert wird auf endlich viele Stufen gerundet.
  • Codierung: Jede Stufe erhält einen digitalen Code (z. B. Binärzahl).
  • Halten: Der DAW hält die rekonstruierte Stufe bis zum nächsten Abtastwert und erzeugt dadurch eine Treppenform.

In umgekehrter Richtung (DAW) läuft es umgekehrt: Code → Stufe → über ein Abtast-Halteglied gehaltenes, treppenförmiges Ausgangssignal. Erst ein nachgeschalteter Tiefpass bzw. Rekonstruktionsfilter glättet dieses Signal.

6.1 Abtastung

Ein kontinuierliches Signal \(u(t)\) wird alle \(T_{a}\) Sekunden abgetastet (Abtastperiode). Für die Amplitude zählt nur der Momentanwert zum Abtastzeitpunkt:

Code 
f_a = MySymbol(r'f_{a}', description='Abtastfrequenz', unit=u.hertz)
T_a = MySymbol(r'T_{a}', description='Abtastperiode', unit=u.second)
f_g = MySymbol(r'f_{g}', description='höchste im Signal enthaltene Frequenz', unit=u.hertz)
QBookHelpers.print_equation(Eq(f_a, 1/T_a), label='eq-abtastfrequenz')
QBookHelpers.print_equation(Gt(f_a, 2*f_g), label='eq-abtasttheorem')

\[ f_{a} = \frac{1}{T_{a}} \tag{6.1}\]

\[ f_{a} > 2 f_{g} \tag{6.2}\]

  • Abtasttheorem (Shannon/Nyquist): Ein ideal bandbegrenztes Signal kann bei idealer Rekonstruktion aus Abtastwerten rekonstruiert werden, wenn die Abtastfrequenz größer als die doppelte höchste Signalfrequenz ist (\(f_a>2f_g\)). Bei \(f_a=2f_g\) kann beispielsweise ein Sinus nur in seinen Nulldurchgängen abgetastet werden. Praktische Anwendungen benötigen einen Frequenzabstand und geeignete Filter.
  • Verletzt man das Theorem, entsteht Aliasing: tiefere „Spiegelfrequenzen” täuschen Signalanteile vor, die im Original nicht vorhanden sind. Diese Verzerrung lässt sich bei bereits überlagerten Signalanteilen nicht zuverlässig nachträglich beseitigen. Deshalb werden eine ausreichend hohe Abtastfrequenz und ein vorgeschaltetes Anti-Aliasing-Filter verwendet.

6.1.1 Die vier Schritte in einer Grafik

Die 4-Quadranten-Darstellung zeigt den Weg vom analogen Signal zum digitalen Code gegen den Uhrzeigersinn — Abtastung (rechts oben), Quantisierung über die Kennlinie (links oben), gehaltenes Treppensignal (links unten), Code (rechts unten):

Code 
f_sig = 1      # Signal-Frequenz in Hz
f_abtast = 12  # Abtastfrequenz in Hz
n_bits = 3     # Auflösung des Quantisierers
u_min, u_max = -1.0, 1.0
U_ms = u_max - u_min   # Messbereichsspannbreite
lsb = U_ms / 2**n_bits # Quantisierungsstufe

t = np.linspace(0, 1, 1000)
u_sin = np.sin(2*np.pi*f_sig*t)
t_s = np.arange(0, 1, 1/f_abtast)          # Abtastzeitpunkte
u_s = np.sin(2*np.pi*f_sig*t_s)            # Momentanwerte
# Gerundete Quotienten verhindern, dass fast gleiche Abtastwerte durch
# Fließkomma-Rundung auf benachbarte Quantisierungsstufen fallen.
quotienten = np.round((u_s - u_min)/lsb, 12)
stufen = np.clip(np.floor(quotienten), 0, 2**n_bits - 1).astype(int)
u_q = u_min + stufen*lsb + lsb/2           # Quantisierte Werte

fig, axs = plt.subplots(2, 2, figsize=(9, 7))
fig.suptitle('Von analog nach digital — vier Schritte', fontsize=12)

# rechts oben: analoges Signal mit Abtastzeitpunkten
ax = axs[0, 1]
ax.plot(t, u_sin, lw=1.2)
ax.plot(t_s, u_s, 'o', color='crimson', ms=4)
for ts_ in t_s:
    ax.axvline(ts_, color='gray', lw=0.5, alpha=0.5)
ax.set_title('① Abtastung', fontsize=10)
ax.set_xlabel('Zeit in s')
ax.set_ylabel('analoge Spannung $u(t)$ in V')
ax.set_ylim(-1.3, 1.3)
ax.grid(True, alpha=0.4)

# links oben: Quantisierungskennlinie
ax = axs[0, 0]
stufenlinie = np.linspace(u_min, u_max, 2**n_bits + 1)
for i in range(2**n_bits):
    y = u_min + i*lsb + lsb/2
    ax.plot([stufenlinie[i], stufenlinie[i+1]], [y, y], color='darkgreen', lw=1.6)
    if i < 2**n_bits - 1:
        ax.plot([stufenlinie[i+1], stufenlinie[i+1]], [y, y + lsb],
                color='darkgreen', lw=1.2, ls=':')
ax.plot(u_s, u_q, 'o', color='crimson', ms=4)
ax.set_title('② Quantisierungskennlinie', fontsize=10)
ax.set_xlabel('Abtastwert $u_{s}$ in V')
ax.set_ylabel('Quantisierter Wert in V')
ax.grid(True, alpha=0.4)

# links unten: gequanteltes, gehaltenes Signal
ax = axs[1, 0]
ax.plot(t, u_sin, color='lightgray', lw=1)
ax.plot(t_s, u_s, 'o', color='crimson', ms=3)
ax.step(t_s, u_q, where='post', color='darkgreen', lw=1.6)
k_err = int(np.argmax(np.abs(u_q - u_s)))   # Abtastwert mit groesstem Fehler
ax.annotate('Quantisierungsfehler $\\Delta Q$',
            xy=(t_s[k_err], u_q[k_err]), xytext=(t_s[k_err] - 0.35, 1.05),
            fontsize=9,
            arrowprops={'arrowstyle': '->', 'color': 'black', 'lw': 0.8})
ax.set_title('③ Gequanteltes, gehaltenes Signal', fontsize=10)
ax.set_xlabel('Zeit in s')
ax.set_ylabel('Stufenwert in V')
ax.set_ylim(-1.3, 1.4)
ax.grid(True, alpha=0.4)

# rechts unten: Ausgangscode
ax = axs[1, 1]
ax.plot(t_s, stufen, drawstyle='steps-post', color='navy', lw=1.4, marker='o', ms=3)
for i in range(0, len(t_s), 2):
    code = format(stufen[i], f'0{n_bits}b')
    ax.text(t_s[i], stufen[i] + 0.25, code, fontsize=8, ha='center', color='navy')
ax.set_title('④ Ausgangscode (3 Bit)', fontsize=10)
ax.set_xlabel('Zeit in s')
ax.set_ylabel('Code-Wert')
ax.set_ylim(-0.5, 7.8)
ax.grid(True, alpha=0.4)

plt.tight_layout()
plt.show()

Der Zahlenwert des Codes entsteht, indem jeder Abtastwert auf die nächste Kennlinien-Stufe gerundet wird — die Schritte der Kennlinie sind die Quantisierungsstufen. Der Quantisierungsfehler ist die Differenz zwischen Abtastwert und Stufenwert im Abtastzeitpunkt. Die Abweichung zwischen den Abtastpunkten entsteht zusätzlich durch das Halten der Stufe.

6.2 Quantisierung

Für \(n\) Bit stehen \(2^{n}\) Stufen über der Messbereichsspannbreite \(U_{ms}\) zur Verfügung:

Code 
n_bit = MySymbol('n', description='Auflösung des Wandlers in Bit')
U_ms = MySymbol(r'U_{ms}', description='Messbereichsspannbreite', unit=u.volt)
dU = MySymbol(r'\Delta U', description='Quantisierungsstufe (1 LSB)', unit=u.volt)
QBookHelpers.print_equation(Eq(dU, U_ms/2**n_bit), label='eq-lsb')

\[ \Delta U = 2^{- n} U_{ms} \tag{6.3}\]

Die Rundung auf die nächste Stufe verursacht den Quantisierungsfehler — maximal eine halbe Stufe:

Code 
dQ = MySymbol(r'\Delta Q', description='maximaler Quantisierungsfehler', unit=u.volt)
QBookHelpers.print_equation(Eq(Abs(dQ), dU/2), label='eq-quantisierungsfehler')

\[ \left|{\Delta Q}\right| = \frac{\Delta U}{2} \tag{6.4}\]

Beispiel 8-Bit-Wandler mit Messbereich \(0\,\mathrm{V} \ldots 10\,\mathrm{V}\):

Code 
U_ms_ex = MySymbol(r'U_{ms}', description='Messbereichsspannbreite', unit=u.volt,
                   value=10)
QBookHelpers.print_values([U_ms_ex])
eq_ex = Eq(dU, U_ms/2**n_bit).subs({U_ms: 10, n_bit: 8})
QBookHelpers.print_equation(Eq(dU, U_ms_ex/2**n_bit).subs({n_bit: 8}), label='eq-lsb-beispiel')
dU_v = MySymbol(r'\Delta U', description='Quantisierungsstufe (1 LSB)', unit=u.volt,
                value=float(eq_ex.rhs))
dQ_v = MySymbol(r'\Delta Q', description='maximaler Quantisierungsfehler', unit=u.volt,
                value=float(eq_ex.rhs/2))
QBookHelpers.print_values([dU_v, dQ_v])

\[U_{ms} = \mathtt{\text{10}} \ \mathtt{\text{V}}\]

\[ \Delta U = \frac{U_{ms}}{256} \tag{6.5}\]

\[\Delta U = \mathtt{\text{39,1}} \ \mathtt{\text{mV}}\]

\[\Delta Q = \mathtt{\text{19,5}} \ \mathtt{\text{mV}}\]

  • Der Quantisierungsfehler ist ein systematischer Effekt; nach GUM wird er als Typ-B-Standardunsicherheit mit gleichverteiltem (rechteckverteiltem) Fehler im Intervall \(\pm \Delta U/2\) bewertet ([1]). Die Standardunsicherheit beträgt \(\Delta U/\sqrt{12}\).

6.3 Kenngrößen von ADW und DAW

Kenngröße Bedeutung
Auflösung Anzahl Stufen \(2^{n}\) bzw. kleinste darstellbare Stufe \(\Delta U\)
Quantisierungsfehler Rundungsfehler durch endliche Stufenzahl, max. \(\pm \Delta U/2\)
Linearität Abweichung der realen Kennlinie von der idealtypischen Geraden durch die Stufenmitten
Genauigkeit Abweichung zwischen Soll- und Ist-Übertragungswert (inkl. Offset- und Verstärkungsfehler)
Umwandlungsdauer Zeitspanne bis zur fertigen Digitalisierung — begrenzt die mögliche Abtastfrequenz
Konversionsrate Anzahl Wandlungen je Sekunde
  • Auflösung und Genauigkeit sind nicht dasselbe: Ein 12-Bit-Wandler mit großem Offset verbessert durch die Auflösung allein nichts.
  • Bei Ungereimtheiten in der Kennlinie spricht man von Differenzlinearität (Stufen ungleich groß) bzw. Integrallinearität (Kennlinie krumm).

6.4 Praktische Wandlerschaltungen

Die folgenden Abschnitte behandeln die praktische Umsetzung der beiden Wandlungsrichtungen. Die DAW-Schaltungen setzen einen digitalen Code um; die ADW-Schaltungen entscheiden den dazugehörigen analogen Messwert.

6.5 DAW-Schaltungen

Verwendete Symbole:

Code 
n_s = MySymbol('n', description='Auflösung des DAW in Bit')
N_s = MySymbol('N', description='Anzahl der Stufen')
U_soll_s = MySymbol(r'U_{Soll}', description='Ausgangsspannung des DAW', unit=u.volt)
U_ref_s = MySymbol(r'U_{Ref}', description='Referenzspannung', unit=u.volt)
D_s = MySymbol('D', description='Tastgrad (Duty Cycle)')
QBookHelpers.print_description([n_s, N_s, U_soll_s, U_ref_s, D_s])

\(n\) … Auflösung des DAW in Bit

\(N\) … Anzahl der Stufen

\(U_{Soll}\) … Ausgangsspannung des DAW

\(U_{Ref}\) … Referenzspannung

\(D\) … Tastgrad (Duty Cycle)

Ein Digital-Analog-Wandler setzt einen digitalen Zahlenwert in eine analoge Ausgangsspannung um. Die digitale Information ist zeitdiskret und quantisiert; das Ausgangssignal ist nach dem Abtast-Halteglied treppenförmig.

6.6 Gewichteter Widerstands-DAW

Bei einem gewichteten Widerstandsnetzwerk erhält jede Eingangsleitung einen Leitwert entsprechend dem Stellenwert des Bits:

Bitstelle Gewicht
höchstwertiges Bit \(2^{n-1}\)
nächstes Bit \(2^{n-2}\)
niedrigstwertiges Bit \(1\)

Die Ausgangsspannung eines idealen Wandlernetzes folgt aus dem normierten Digitalcode:

Code 
n = MySymbol('n', description='Auflösung in Bit')
N = MySymbol('N', description='Anzahl der Stufen')
U_ref = MySymbol(r'U_{Ref}', description='Referenzspannung', unit=u.volt)
U_soll = MySymbol(r'U_{Soll}', description='Ausgangsspannung', unit=u.volt)
k = MySymbol('k', description='Digitalcode', )
QBookHelpers.print_description([n, N, U_ref, U_soll, k])
QBookHelpers.print_equation(Eq(N, 2**n), label='eq-daw-stufen')
QBookHelpers.print_equation(Eq(U_soll, U_ref*k/N), label='eq-daw-ausgang')

\(n\) … Auflösung in Bit

\(N\) … Anzahl der Stufen

\(U_{Ref}\) … Referenzspannung

\(U_{Soll}\) … Ausgangsspannung

\(k\) … Digitalcode

\[ N = 2^{n} \tag{6.6}\]

\[ U_{Soll} = \frac{U_{Ref} k}{N} \tag{6.7}\]

Mit \(n=3\), \(N=8\) und \(U_{Ref}=5\,\mathrm{V}\) ergibt sich für den Code \(k=5\):

Code 
U_ref_v = MySymbol(r'U_{Ref}', description='Referenzspannung', unit=u.volt, value=5)
k_v = MySymbol('k', description='Digitalcode', value=5)
N_v = MySymbol('N', description='Anzahl der Stufen', value=8)
U_soll_v = MySymbol(r'U_{Soll}', description='Ausgangsspannung', unit=u.volt,
                    value=5*5/8)
QBookHelpers.print_values([U_ref_v, k_v, N_v, U_soll_v])

\[U_{Ref} = \mathtt{\text{5}} \ \mathtt{\text{V}}\]

\[k = \mathtt{\text{5}} \ \mathtt{\text{}}\]

\[N = \mathtt{\text{8}} \ \mathtt{\text{}}\]

\[U_{Soll} = \mathtt{\text{3,12}} \ \mathtt{\text{V}}\]

  • Der gewichtete Aufbau benötigt für hohe Auflösungen sehr unterschiedliche Widerstandswerte.
  • Genauigkeitsanforderungen wachsen mit der höchsten Auflösung; schon der Widerstand des höchstwertigen Zweiges muss sehr exakt sein.
  • Die Bauart ist einfach zu verstehen, wird für höhere Bitzahlen aber weniger praktisch.

6.7 R-2R-Netzwerk

Das R-2R-Netzwerk verwendet nur die Widerstandswerte \(R\) und \(2R\). Dadurch werden Fertigung und Abgleich bei integrierten DAW einfacher.

Code 
from matplotlib.patches import Rectangle

fig, ax = plt.subplots(figsize=(9, 4.2))

def draw_resistor_horizontal(x1, x2, y, label):
    lead = 0.12
    ax.plot([x1, x1 + lead, x2 - lead, x2],
            [y, y, y, y], color='black', linewidth=1.5)
    ax.add_patch(Rectangle((x1 + lead, y - 0.10),
                           x2 - x1 - 2*lead, 0.20,
                           facecolor='white', edgecolor='black', linewidth=1.5))
    ax.text((x1 + x2)/2, y + 0.28, label,
            ha='center', va='bottom', fontsize=10)

def draw_resistor_vertical(x, y1, y2, label):
    lead = 0.12
    ax.plot([x, x, x, x],
            [y1, y1 + lead, y2 - lead, y2],
            color='black', linewidth=1.5)
    ax.add_patch(Rectangle((x - 0.10, y1 + lead),
                           0.20, y2 - y1 - 2*lead,
                           facecolor='white', edgecolor='black', linewidth=1.5))
    ax.text(x + 0.32, (y1 + y2)/2, label,
            ha='left', va='center', fontsize=10)

node_x = [1.0, 2.8, 4.6, 6.4]
rail_y = 3.2
ground_y = 0.8

# Serienwiderstände 2R
for x1, x2 in zip([0.1, *node_x[:-1]], node_x):
    draw_resistor_horizontal(x1, x2, rail_y, r'$2R$')

# Abschließender Serienwiderstand und Ausgang
draw_resistor_horizontal(node_x[-1], 7.7, rail_y, r'$2R$')
ax.plot([7.7, 8.2], [rail_y, rail_y], color='black', linewidth=1.5)
ax.text(8.35, rail_y, r'$U_\mathrm{out}$',
        ha='left', va='center', fontsize=12)

# Verzweigungswiderstände R zu den Bitstellen
for i, x in enumerate(node_x):
    ax.plot([x, x], [rail_y - 0.10, ground_y + 0.10],
            color='black', linewidth=1.5)
    draw_resistor_vertical(x, ground_y + 0.10, rail_y - 0.10, r'$R$')
    ax.plot([x - 0.38, x - 0.38], [ground_y, ground_y - 0.35],
            color='black', linewidth=1.5)
    ax.text(x - 0.38, ground_y - 0.50,
            f'$D_{len(node_x)-i-1}$',
            ha='center', va='top', fontsize=11)

ax.plot([0.1, 0.1], [rail_y, rail_y + 0.65],
        color='black', linewidth=1.5)
ax.text(0.1, rail_y + 0.82, r'$U_\mathrm{Ref}$',
        ha='center', va='bottom', fontsize=12)

ax.plot([node_x[0] - 0.38, node_x[-1] + 0.38],
        [ground_y - 0.35, ground_y - 0.35],
        color='black', linewidth=1.0)

ax.set_xlim(-0.2, 9.2)
ax.set_ylim(0.1, 4.2)
ax.set_aspect('equal')
ax.axis('off')
plt.tight_layout()
plt.show()
Code 
codes = np.arange(8)
u_out = 5*codes/8

plt.plot(codes, u_out, 'o-', color='navy')
plt.xticks(codes, [format(code, '03b') for code in codes])
plt.xlabel('3-Bit-Code')
plt.ylabel('Ausgangsspannung in V')
plt.title('Ideale DAW-Kennlinie')
plt.grid(True)
plt.ylim(-0.2, 5.2)
plt.show()

Jeder Stufenschritt entspricht einem 1-LSB-Wert:

Code 
U_ref_r2r = MySymbol(r'U_{Ref}', description='Referenzspannung', unit=u.volt)
n_r2r = MySymbol('n', description='Auflösung in Bit')
dU_r2r = MySymbol(r'\Delta U', description='Stufenspannung (1 LSB)', unit=u.volt)
QBookHelpers.print_description([U_ref_r2r, n_r2r, dU_r2r])
QBookHelpers.print_equation(Eq(dU_r2r, U_ref_r2r/2**n_r2r),
                           label='eq-r2r-lsb')

\(U_{Ref}\) … Referenzspannung

\(n\) … Auflösung in Bit

\(\Delta U\) … Stufenspannung (1 LSB)

\[ \Delta U = 2^{- n} U_{Ref} \tag{6.8}\]

  • Alle Knoten sind nur mit \(R\) oder \(2R\) verbunden.
  • Das Netzwerk lässt sich gut integrieren und durch Umschalten der Referenzzweige ausführen.
  • Stromquellen-, Referenz- und Operationsverstärkerfehler beeinflussen die Gesamtgenauigkeit.

6.8 Interpolierender DAW

Ein interpolierender DAW setzt die grobe Auflösung aus Widerstands- oder Stromquellenstufen um und steigert die Feinauflösung durch einen zweiten Wandlerabschnitt.

Code 
n_grob = MySymbol(r'n_{grob}', description='grobe Auflösung in Bit')
n_fein = MySymbol(r'n_{fein}', description='feine Auflösung in Bit')
n_interp = MySymbol(r'n_{ges}', description='Gesamtauflösung in Bit')
QBookHelpers.print_description([n_grob, n_fein, n_interp])
QBookHelpers.print_equation(Eq(n_interp, n_grob+n_fein),
                           label='eq-interpolierende-auflösung')

\(n_{grob}\) … grobe Auflösung in Bit

\(n_{fein}\) … feine Auflösung in Bit

\(n_{ges}\) … Gesamtauflösung in Bit

\[ n_{ges} = n_{fein} + n_{grob} \tag{6.9}\]

Ein 6-Bit-Grobsegment und ein 4-Bit-Feinsegment ergeben daher:

Code 
n_grob_v = MySymbol(r'n_{grob}', description='grobe Auflösung in Bit', value=6)
n_fein_v = MySymbol(r'n_{fein}', description='feine Auflösung in Bit', value=4)
n_interp_v = MySymbol(r'n_{ges}', description='Gesamtauflösung in Bit', value=10)
QBookHelpers.print_values([n_grob_v, n_fein_v, n_interp_v])

\[n_{grob} = \mathtt{\text{6}} \ \mathtt{\text{}}\]

\[n_{fein} = \mathtt{\text{4}} \ \mathtt{\text{}}\]

\[n_{ges} = \mathtt{\text{10}} \ \mathtt{\text{}}\]

Der Vorteil entsteht durch die Trennung von grober und feiner Stufung: weniger parallel geschaltete Bauelemente bei gleicher Gesamtauflösung.

6.9 PWM als Digital-Analog-Wandlung

Bei einer pulsweitenmodulierten Ausgangsspannung wird eine Rechteckspannung mit konstanter Periodendauer \(T\) erzeugt. Der Tastgrad \(D\) bestimmt den zeitlichen Mittelwert:

Code 
T_pwm = MySymbol('T', description='PWM-Periode', unit=u.second)
t_ein = MySymbol(r't_{ein}', description='Einschaltdauer', unit=u.second)
D_pwm = MySymbol('D', description='Tastgrad')
U_pwm = MySymbol(r'\bar{U}', description='gemittelter Ausgang', unit=u.volt)
U_v = MySymbol(r'U_{0}', description='Pegel der eingeschalteten Spannung', unit=u.volt)
QBookHelpers.print_description([T_pwm, t_ein, D_pwm, U_pwm, U_v])
QBookHelpers.print_equation(Eq(D_pwm, t_ein/T_pwm),
                           label='eq-pwm-tastgrad')
QBookHelpers.print_equation(Eq(U_pwm, D_pwm*U_v),
                           label='eq-pwm-mittelwert')

\(T\) … PWM-Periode

\(t_{ein}\) … Einschaltdauer

\(D\) … Tastgrad

\(\bar{U}\) … gemittelter Ausgang

\(U_{0}\) … Pegel der eingeschalteten Spannung

\[ D = \frac{t_{ein}}{T} \tag{6.10}\]

\[ \bar{U} = D U_{0} \tag{6.11}\]

Code 
T_pwm_plot = 1
t = np.linspace(0, 3*T_pwm_plot, 3000)

fig, axes = plt.subplots(3, 1, figsize=(8, 5), sharex=True)
for ax, D in zip(axes, (0.25, 0.50, 0.75)):
    duty = np.mod(t, T_pwm_plot) < D*T_pwm_plot
    ax.plot(t, duty, drawstyle='steps-post', lw=1.5)
    ax.set_ylim(-0.2, 1.2)
    ax.set_yticks([])
    ax.set_ylabel(f'$D={D:.2f}$', rotation=0, ha='right', va='center')
    ax.grid(True, alpha=0.3)
axes[-1].set_xlabel('Zeit in s')
plt.tight_layout()
plt.show()
  • Der Tiefpass bzw. das mechanische bzw. elektrische System bildet den Mittelwert.
  • Bei hohen Abtast- oder Schaltfrequenzen ist das Ausgangssignal weniger zeitabhängig, aber die Schaltverluste steigen.
  • PWM eignet sich besonders für Leistungssteller, Motoren und leistungssensitive Digitalausgänge.

6.10 Anwendung und Auswahl

DAW-Bauart Vorteile Grenzen
Gewichtetes Widerstandsnetzwerk einfach verständlich stark unterschiedliche Widerstände
R-2R-Netzwerk nur zwei Widerstandswerte, gut integrierbar Referenz- und Operationsverstärkerfehler
Interpolierender DAW hohe Auflösung bei weniger Bauelementen zweistufige Kennlinien müssen abgestimmt sein
PWM einfach digital steuerbar, leistungsstark erfordert Tiefpass bzw. träges System

6.12 Messende Verfahren

Beim Vergleichsverfahren wird der Eingangswert wiederholt mit einer bekannten Spannung verglichen. Die Konversionsdauer steigt je nach Verfahren mit der Auflösung oder bleibt für alle Eingangswerte gleich.

Code 
n = MySymbol('n', description='Auflösung in Bit')
t_clk = MySymbol(r'T_{clk}', description='Taktperiode', unit=u.second)
t_sar = MySymbol(r't_{SAR}', description='Umwandlungsdauer beim sukzessiven Approximation', unit=u.second)
f_c = MySymbol(r'f_{c}', description='Konversionsrate', unit=u.hertz)
t_c = MySymbol(r't_{c}', description='Umwandlungsdauer', unit=u.second)
QBookHelpers.print_description([n, t_clk, t_sar, f_c, t_c])
QBookHelpers.print_equation(Eq(t_sar, n*t_clk),
                           label='eq-sar-umwandlungsdauer')
QBookHelpers.print_equation(Eq(f_c, 1/t_c),
                           label='eq-konversionsrate')

\(n\) … Auflösung in Bit

\(T_{clk}\) … Taktperiode

\(t_{SAR}\) … Umwandlungsdauer beim sukzessiven Approximation

\(f_{c}\) … Konversionsrate

\(t_{c}\) … Umwandlungsdauer

\[ t_{SAR} = T_{clk} n \tag{6.12}\]

\[ f_{c} = \frac{1}{t_{c}} \tag{6.13}\]

Für \(n=12\) Bit und \(T_{clk}=100\,\mathrm{ns}\) ergibt der SAR-Algorithmus:

Code 
n_v = MySymbol('n', description='Auflösung in Bit', value=12)

                 value=1/(12*100e-9))

\[T_{clk} = \mathtt{\text{100}} \ \mathtt{\text{ns}}\]

\[t_{SAR} = \mathtt{\text{1,2}} \ \mathtt{\text{us}}\]

6.13 Sukzessive Approximation

Ein SAR-Wandler (Successive Approximation Register) tastet den Eingang ab und setzt das höchstwertige Bit. Anschließend wird geprüft, ob das Ergebnis zu hoch oder zu niedrig ist. Das nächste Bit wird entsprechend gesetzt oder gelöscht. Die Schritte wiederholen sich, bis alle Bits entschieden sind.

Code 
u_in = 7.3
u_ref = 10
n_sar = 4
stufen = 2**n_sar

code = 0
decision = []
u_test_values = []
for bit_index in range(n_sar):
    candidate = code | (1 << (n_sar - 1 - bit_index))
    u_test = u_ref*candidate/stufen
    accepted = u_test <= u_in
    if accepted:
        code = candidate
    decision.append(accepted)
    u_test_values.append(u_test)

fig, ax = plt.subplots()
ax.step(np.arange(1, n_sar+1), u_test_values, where='mid',
        marker='o', color='navy', label='Vergleichsspannung')
ax.axhline(u_in, color='crimson', ls='--', label='$U_{in}$')
for i, (u_test, accepted) in enumerate(zip(u_test_values, decision), 1):
    ax.text(i, u_test + 0.25, '1' if accepted else '0',
            ha='center', color='darkgreen' if accepted else 'darkred')
ax.set_xlabel('Vergleichsschritt')
ax.set_ylabel('Spannung in V')
ax.set_xticks(np.arange(1, n_sar+1))
ax.set_ylim(0, 10.5)
ax.grid(True)
ax.legend()
plt.show()
  • Vorteil: hoher Kompromiss aus Genauigkeit, Geschwindigkeit und Aufwand.
  • Nachteil: der DAW-, Vergleichs- und Referenzteil bestimmt die Genauigkeit.
  • Einsatz: Datenlogger, Messverstärker, Mikrocontroller-Peripherie.

6.14 Rampenverfahren

Beim Rampenverfahren wird ein Zähler mit einer linearen Vergleichsspannung verglichen. Der Zähler steht still, sobald die Rampe den Eingang erreicht hat.

Code 
n_rampe = MySymbol('n', description='Auflösung in Bit')
t_rampe = MySymbol(r't_{Rampe}', description='Umwandlungszeit', unit=u.second)
U_ref_rampe = MySymbol(r'U_{Ref}', description='Referenzspannung', unit=u.volt)
U_in_rampe = MySymbol(r'U_{in}', description='Eingangsspannung', unit=u.volt)
QBookHelpers.print_description([n_rampe, t_rampe, U_ref_rampe, U_in_rampe])
QBookHelpers.print_equation(Eq(t_rampe, U_in_rampe/U_ref_rampe*2**n_rampe*t_clk),
                           label='eq-rampenzeit')

\(n\) … Auflösung in Bit

\(t_{Rampe}\) … Umwandlungszeit

\(U_{Ref}\) … Referenzspannung

\(U_{in}\) … Eingangsspannung

\[ t_{Rampe} = \frac{2^{n} T_{clk} U_{in}}{U_{Ref}} \tag{6.14}\]

  • Die Umwandlungszeit hängt direkt vom Eingangswert ab.
  • Vorteil: einfache digitale Zähl- und Vergleichslogik.
  • Nachteil: geringe Geschwindigkeit und störanfällige Messung bei variablen Eingangswerten.

6.15 Parallelwandler

Ein Parallelwandler oder Flash-Wandler vergleicht den Eingang gleichzeitig mit allen Stufen eines Widerstandsnetzwerks. Ein Prioritätskodierer erzeugt den Code.

Für \(n\) Bit werden ideal \(2^{n}-1\) Vergleichsstufen benötigt:

Code 
n_flash = MySymbol('n', description='Auflösung in Bit')
M_flash = MySymbol('M', description='Anzahl der Vergleichsstufen')
QBookHelpers.print_description([n_flash, M_flash])
QBookHelpers.print_equation(Eq(M_flash, 2**n_flash-1),
                           label='eq-flash-vergleicher')

\(n\) … Auflösung in Bit

\(M\) … Anzahl der Vergleichsstufen

\[ M = 2^{n} - 1 \tag{6.15}\]

Code 
n_flash_plot = 3
u_ref_plot = 8
thresholds = np.arange(1, 2**n_flash_plot)*u_ref_plot/(2**n_flash_plot)
u_input = 5.2
code_flash = int(np.sum(u_input >= thresholds))

fig, ax = plt.subplots()
for i, threshold in enumerate(thresholds, 1):
    ax.axhline(threshold, color='gray', lw=1)
    ax.text(0.05, threshold+0.08, f'$V_{i}$', fontsize=8)
ax.axhspan(0, u_input, color='tab:blue', alpha=0.12)
ax.axhline(u_input, color='crimson', lw=2, label=f'$U_{{in}}={u_input:g}$ V')
ax.plot([0, 1], [u_input, u_input], color='crimson')
ax.text(0.75, u_ref_plot*0.96,
        f'Code = {code_flash:03b}',
        ha='right', va='top', color='navy',
        bbox=dict(boxstyle='round', facecolor='white', alpha=0.8))
ax.set_xlim(0, 1)
ax.set_xticks([])
ax.set_ylim(0, u_ref_plot)
ax.set_ylabel('Spannung in V')
ax.grid(False)
ax.legend(loc='lower left')
plt.show()
  • Vorteil: sehr kurze Umwandlungsdauer, weil alle Vergleiche parallel laufen.
  • Nachteil: exponentiell steigender Bauteilaufwand.
  • Einsatz: schnelle Oszilloskope, Kommunikationssysteme und Videoaufnehmer.

6.16 Sigma-Delta-Wandler

Ein Sigma-Delta-Wandler misst nicht in einem einzelnen Vergleichsentscheid, sondern über eine Modulation: Eingangs- und Rückkopplungssignal werden integriert, ein 1-Bit-Quantisierer entscheidet dauernd.

Code 
M_s = MySymbol('M', description='Überabtastungsfaktor')
f_s = MySymbol(r'f_{s}', description='Abtastfrequenz', unit=u.hertz)
f_b = MySymbol(r'f_{B}', description='Signalbandbreite', unit=u.hertz)
QBookHelpers.print_description([M_s, f_s, f_b])
QBookHelpers.print_equation(Eq(f_s, M_s*f_b),
                           label='eq-sigma-delta-abtastung')

\(M\) … Überabtastungsfaktor

\(f_{s}\) … Abtastfrequenz

\(f_{B}\) … Signalbandbreite

\[ f_{s} = M f_{B} \tag{6.16}\]

Die Überabtastung bewegt Quantisierungsrauschen in höhere Frequenzbereiche. Ein nachgeschalteter Digitalfilter entfernt diesen Anteil und erhöht zugleich die Auflösung.

Code 
f_norm = np.linspace(0, 1, 500)
noise_1 = f_norm**0
noise_2 = f_norm**2
noise_4 = f_norm**4

fig, ax = plt.subplots()
ax.plot(f_norm, noise_1, color='gray', ls=':', label='1. Ordnung')
ax.plot(f_norm, noise_2, color='tab:blue', label='2. Ordnung')
ax.plot(f_norm, noise_4, color='tab:red', label='höhere Ordnung')
ax.axvspan(0, 0.10, color='tab:green', alpha=0.12, label='Nutznutzband')
ax.set_xlabel('normierte Frequenz')
ax.set_ylabel('normierte Rauschdichte')
ax.set_ylim(0, 1.05)
ax.grid(True)
ax.legend(fontsize=9)
plt.show()
  • Vorteil: sehr hohe Auflösung bei niedriger Analogschaltungskomplexität.
  • Nachteil: hohe digitale Verarbeitung und begrenzte Umwandlungsbandbreite.
  • Einsatz: Präzisionsmessung, Audio, Sensor-Signalaufbereitung.
