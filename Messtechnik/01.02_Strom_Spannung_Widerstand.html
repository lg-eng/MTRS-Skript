2  Strom-, Spannungs- und Widerstandsmessung

Verwendete Symbole:

\(U_{q}\) … Leerlaufspannung der Quelle

\(R_{q}\) … Innenwiderstand der Quelle

\(R_{V}\) … Innenwiderstand des Voltmeters

\(R_{A}\) … Innenwiderstand des Amperemeters

\(U_{mess}\) … angezeigte Spannung

\(\delta_{U}\) … relative Messabweichung der Spannungsmessung

\(I_{mess}\) … angezeigter Strom

\(\delta_{I}\) … relative Messabweichung der Strommessung

\(R\) … gemessener Widerstand

\(R_{mess}\) … angezeigter Widerstand

2.1 Ideale und reale Messgeräte

Messgerät ideal real
Voltmeter \(R_V \to \infty\) (stromlos) endlicher \(R_V\) (z. B. 10 M\(\Omega\))
Amperemeter \(R_A \to 0\) (spannungslos) kleiner, aber endlicher \(R_A\)

Konsequenz: jedes reale Messgerät entnimmt der Schaltung Energie und verändert damit die zu messende Größe — eine systematische Messabweichung durch Rückwirkung; sie wird berechnet, korrigiert und ihr Restanteil geht ins Unsicherheitsbudget (Kapitel 1.3).

2.2 Spannungsrichtige und stromrichtige Schaltung

Code 
U_q = MySymbol('U_q', description='Leerlaufspannung der Quelle', unit=u.volt, value=10)
R_q = MySymbol('R_q', description='Innenwiderstand der Quelle', unit=u.ohm, value=10e3)
R_V = MySymbol('R_V', description='Innenwiderstand des Voltmeters', unit=u.ohm, value=1e6)
R_A = MySymbol('R_A', description='Innenwiderstand des Amperemeters', unit=u.ohm, value=1)
QBookHelpers.print_description([U_q, R_q, R_V, R_A])

\(U_{q}\) … Leerlaufspannung der Quelle

\(R_{q}\) … Innenwiderstand der Quelle

\(R_{V}\) … Innenwiderstand des Voltmeters

\(R_{A}\) … Innenwiderstand des Amperemeters

Spannungsrichtig — Voltmeter liegt direkt am Verbraucher; die Messabweichung rührt vom Spannungsteiler aus \(R_V\) und \(R_q\):

Code 
U_mess = Symbol('U_{mess}')
delta_U = Symbol(r'\delta_U')
eq_umess = Eq(U_mess, U_q*R_V/(R_q + R_V))
eq_du = Eq(delta_U, simplify(eq_umess.rhs/U_q - 1))
QBookHelpers.print_equation(eq_umess, label='eq-umess')
QBookHelpers.print_equation(eq_du, label='eq-delta-u')

\[ U_{mess} = \frac{R_{V} U_{q}}{R_{V} + R_{q}} \tag{2.1}\]

\[ \delta_{U} = - \frac{R_{q}}{R_{V} + R_{q}} \tag{2.2}\]

Stromrichtig — Amperemeter liegt in Reihe; sein Widerstand verringert den Strom:

Code 
I_mess = Symbol('I_{mess}')
delta_I = Symbol(r'\delta_I')
eq_imess = Eq(I_mess, U_q/(R_q + R_A))
eq_di = Eq(delta_I, simplify(eq_imess.rhs*R_q/U_q - 1))
QBookHelpers.print_equation(eq_imess, label='eq-imess')
QBookHelpers.print_equation(eq_di, label='eq-delta-i')

\[ I_{mess} = \frac{U_{q}}{R_{A} + R_{q}} \tag{2.3}\]

\[ \delta_{I} = - \frac{R_{A}}{R_{A} + R_{q}} \tag{2.4}\]

  • Faustregel: \(R_V \gg R_q\) bzw. \(R_A \ll R_q\) — mindestens zwei Zehnerpotenzen Abstand, damit die Rückwirkungsabweichung unter 1 % bleibt.
  • Zusammenspiel beider Abweichungen über dem Widerstandsverhältnis:
Code 
ratio = np.logspace(-3, 2, 300)
delta_u_num = -ratio/(1 + ratio)*100
delta_i_num = -ratio/(1 + ratio)*100
fig, ax = plt.subplots(figsize=(5.5, 3.2))
ax.loglog(ratio, -delta_u_num, label='Spannungsmessung: $R_q/R_V$')
ax.loglog(ratio, -delta_i_num, ls='--', label='Strommessung: $R_A/R_q$')
ax.axhline(1.0, color='gray', lw=1, ls=':')
ax.text(0.0013, 1.05, '1 %', fontsize=9, color='gray')
ax.set_xlabel('Widerstandsverhältnis')
ax.set_ylabel('relative Abweichung $|\\delta|$ in %')
ax.legend(fontsize=9)
plt.show()

Rechenbeispiel — Quelle mit \(R_q = 10\,\mathrm{k\Omega}\), gemessen mit \(R_V = 1\,\mathrm{M\Omega}\):

Code 
U_num = U_q.value*R_V.value/(R_q.value + R_V.value)
dU_num = (U_num/U_q.value - 1)*100
U_v = MySymbol('U_{mess}', description='angezeigte Spannung', unit=u.volt, value=float(U_num))
QBookHelpers.print_values([U_v])
QBookHelpers.print_equation(Eq(delta_U, Float(dU_num, 3)), label='eq-delta-u-num')

\[U_{mess} = \mathtt{\text{9,9}} \ \mathtt{\text{V}}\]

\[ \delta_{U} = -0.99 \tag{2.5}\]

Die Abweichung \(\delta_U\) ist in Prozent. Mit \(R_V = 10\,\mathrm{M\Omega}\) (typisches DMM) sinkt sie auf \(-0{,}1\,\%\).

Wird stattdessen stromrichtig an einer Quelle mit \(R_q = 100\,\Omega\) mit \(R_A = 1\,\Omega\) gemessen:

Code 
dI_num = (-R_A.value/(100 + R_A.value))*100
QBookHelpers.print_equation(Eq(delta_I, Float(dI_num, 3)), label='eq-delta-i-num')

\[ \delta_{I} = -0.99 \tag{2.6}\]

Platzhalter — Messschaltung mit modernen Messgeräten: Foto einer spannungs- und stromrichtigen Messanordnung mit zeitgemäßem Netzteil, digitalem Voltmeter und digitalem Amperemeter. Deutlich sichtbar: Verbraucher, Schutzbeschaltung, Messbereichseinstellung, Reihen- und Parallelschaltung der Messgeräte.

2.3 Widerstandsmessung

Amperemeter-Voltmeter-Methode. Aus \(R = U/I\) mit zwei Schaltvarianten:

  • Spannungsrichtig (Amperemeter misst auch Voltmeterstrom) — geeignet für kleine Widerstände (\(R \ll R_V\)):
Code 
R_x = Symbol('R')
R_mess = Symbol('R_{mess}')
QBookHelpers.print_equation(Eq(R_mess, R_x*R_V/(R_x + R_V)), label='eq-r-spannungsrichtig')

\[ R_{mess} = \frac{R_{V} R}{R_{V} + R} \tag{2.7}\]

  • Stromrichtig (Voltmeter misst auch Amperemeterspannung) — geeignet für große Widerstände (\(R \gg R_A\)):
Code 
QBookHelpers.print_equation(Eq(R_mess, R_x + R_A), label='eq-r-stromrichtig')

\[ R_{mess} = R_{A} + R \tag{2.8}\]

Direkte Widerstandsmessung mit dem Multimeter.

  • Das DMM speist einen konstanten Messstrom und misst den Spannungsabfall: \(R = U_{ab}/I_{mess}\).
  • Vierleitertechnik (4-Wire): Messstrom fließt über eigene Zuleitungen, die Spannung wird über stromlose Sensingleitungen abgegriffen — Zuleitungs- und Kontaktwiderstände fallen aus dem Ergebnis heraus. Standard bei kleinen Widerständen (Shunts).
  • Hinweis: Widerstandsmessung nur an spannungsfreien, stromlosen Schaltungen.
